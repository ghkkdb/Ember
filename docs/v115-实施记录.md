# 1.15 适配、紧凑信息与战斗反馈

更新日期：2026-11-18。

## 武器与饰品显示

- 删除独立参数框，统一为两行紧凑文本：伤害／间隔、距离／暴击。商店展开详情不再重复这些数值。
- 取消独立回合伤害弹窗、占比条及伤害构成列表，回合结束直接按原顺序领取奖励、进入商店。
- 对应武器槽只显示“本轮伤害：数值”，按实例匹配上一轮快照；同名武器分开统计，新购武器为0。存档继续后仍可查看。
- 饰品货架显示“当前适配X/N把”及武器名；依据武器属性系数、攻击机制及特定配件规则判断。暂无适配、暴击未溢出、通用生存／机动／经济收益分别说明；收益与代价仍以道具描述为准，不把适配等同于必然提升最终输出。
- 两款重名武器分别改为“重栓连射器”和“重栓穿甲枪”，保留原ID，兼容既有存档。近战上限说明改为读取配置的8.4，避免面板残留6.0。

## 移动端与镜头

- 竖屏在主菜单、战斗HUD和暂停界面提示推荐横屏，不强制旋转或中断游戏。
- 设置与暂停面板均提供32、40、48、56四档视角高度，默认40，保存到生涯设置。
- 微倾镜头同步调整高度和后移距离；正交模式同步调整可见范围，切换视角、持续跟随和窗口缩放继续使用所选高度比例。
- 手机横屏商店货架两列，武器槽三列；竖屏保留两列武器槽，按钮保留触摸尺寸。

## 击杀反馈

- 击杀时复用原小怪模型，短暂压扁、向外倒退并缩小，0.18秒后进入分帧释放队列；伤害、击杀与掉落立即结算。
- 配合武器色爆裂环和短促低音击杀音效，不使用整屏白闪、逐只点光或镜头震动。
- 每80毫秒最多保留桌面3个／手机2个新倒地效果，并发最多6／4个；其余直接进入原释放队列。命中、粒子、特效总量仍受1.14预算限制。
