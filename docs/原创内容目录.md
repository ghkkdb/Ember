## 武器的共用预算

普通武器表均以I阶等效基础值记录。开放波次与最低品质分离：某款武器较晚开放，也不能把其I阶基础值再次当成高阶基础值重复乘算。沿用品质伤害倍率1/1.5/2.25/3.4，后续是否需要修改由实测决定。

“属性”是一轮完整攻击对同一目标的总属性系数，按命中段拆分；不是每枚弹、每跳DOT或每台构装都获得整份系数。不同敌人之间不分摊伤害。直接命中可暴击，DOT不暴击；初稿普通武器自带暴击统一5%，个别例外须显式配置。价格为基价，实际售价仍应用商店与波次系数。

暴击效果角色初始为0，最终暴击倍率为`max(1, 1.75 + 有效暴击效果%/100)`。I49仅转换每把武器超过100%的原始总暴击率，不扣除已达到的100%，不改变不可暴击伤害的资格；转换值按每把武器计算，不能写回成全局属性再反复转换。

本目录中的“短距离、宽弧、远程、领域、轨道”等描述都需采用缩小后的基础尺度，不沿用旧版大范围。已有对应机制先按1.7基础距离和伤害区域半径的70%起测，新机制按同档尺度配置。范围属性影响拾取与攻击可达距离，不同时提高爆炸半径、领域面积和连锁跳距；这些只由明确的机制配件或核心改变。

近战最终距离初稿为不超过缩小后基础值1.75倍，且不超过6.0世界单位，取较小者；轨道接触同样受限，与伤害使用近战、远程或魔法属性无关。远程投掷、弹丸、法术和构装攻击不设置射程硬上限，按统一范围规则计算。所有局部距离增益在最终上限前结算，模型与实际判定同步。

30款普通武器各有一个主羁绊，机制标签可以多个，不因混合伤害同时白送两类羁绊计数。所有核心、专武和道具的额外伤害均遵守衍生效果不递归的规则。

## 6位原创Boss

技能表中的伤害为难度1、第5波原型原始伤害；更高难度首版只增加生命。接触伤害统一先按4设计，预警与硬直期间关闭，避免玩家靠近输出被不透明接触伤害反复惩罚。

共用节奏：追击/调整位置约2.8秒 → 选择一个技能 → 完整预警 → 执行 → 硬直。不同技能之间不同时铺满场地；生命≤50%改变下一轮技能，不缩短当前预警。所有预警至少0.65秒，组合技至少保留一条可走通的安全路线。

装备文案：“暴击率达到100%后，溢出的暴击率按2：1转化为暴击效果。”100%恰好达到时不转化；原始140%时，额外暴击效果+20%，角色原有暴击效果为0时暴击倍率变为1.95。小数保留，例如101%产生+0.5%，不提前取整。没有超额暴击时此装备不提供收益，商店需显示当前各武器的预计转化量。

转换使用角色、武器自带与当前合法条件的未截断总暴击率。装备卸下、条件失效或武器替换立即重算；不消耗暴击率、不永久修改属性、不允许多件转换器叠加。角色面板展示自身暴击效果，武器详情另显示本武器的转换值和最终倍率。
