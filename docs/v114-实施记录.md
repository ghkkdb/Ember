# 1.14 武器信息、回合战报与流畅体验

更新日期：2026-11-18。

## 信息与战报

- 武器信息统一展示单次分段伤害、释放间隔、攻击距离、主击暴击率；核心适配直接可见，机制、属性系数与获取方式收进展开详情。商店展示当前构筑数值，图鉴保持中性基准。
- 战斗顶部武器槽可点击或触摸，打开详情时暂停，关闭后恢复原状态，同时显示该武器实例本轮已造成的有效伤害。
- 普通回合完成后先展示战报，再按原顺序领取宝箱、升级、Boss奖励与核心，最后进入商店；自动拾取在战报前结算。
- 同名武器按实例和槽位分别统计；零输出武器也显示。战报列出有效伤害、占比、直击/追加/持续构成，以及按整轮实际计时计算的平均每秒伤害。冲刺等未归属武器的伤害单独列出。
- 只计入实际扣除的敌人生命，排除场景道具和过量伤害。保留原有按武器ID汇总账本，增加实例账本，兼容旧存档。
- 商店可重新展开查看本轮战报；胜利与失败界面均显示当轮数据。回合快照连同最后一轮存档保存，买卖武器或下一波不会改写历史记录。

## 移动端

- 手机HUD采用两列生命/波次布局、紧凑武器槽和暂停按钮；右下角独立大尺寸冲刺按钮避开安全区。
- 视角、音效、辉光和群落切换收进暂停面板，内容图鉴入口仍可用。商店主要操作采用两列44像素触摸按钮，武器名允许换行，装备两列展示。
- 详情、暂停与结算面板限制在动态屏高内滚动；战报只有武器列表滚动，继续按钮保持可见；支持横屏和安全区。
- 移动端渲染像素比上限1.25，启动时阴影1024；后处理像素比上限1.25。按触屏能力或窄屏识别移动设备，旋转后继续使用对应预算。

## 密集击杀反馈

- 每50毫秒共享命中反馈预算：桌面3次、移动端2次，合并音效、命中特效与伤害数字；全部敌人仍正常结算伤害、掉落和击杀。
- 普通命中、暴击和持续伤害不再逐只触发镜头震动与暴击点光；重击、终结及Boss直接命中保留小幅反馈。震动使用最大值，不累加；上限桌面0.18、移动端0.10。
- 点光每120毫秒最多触发一次，强度上限1.2；命中特效不再转为纯白，火花改为低亮暖色，降低命中特效透明度及全局辉光。
- 瞬时效果并发上限桌面56、移动端32，新建预算每50毫秒18/10个；满额后跳过新建，避免逐个销毁再重建。
- 粒子并发上限56/36，新建预算每50毫秒24/12个；普通死亡只请求3个溶解粒子，网格复用。缩小粒子代替修改共享材质透明度，避免污染其它物体。
- 普通小怪死亡后立即移出场景与敌人列表，独立资源按每次战斗更新4/2个分帧释放；回合清场时排空队列。Boss仍即时释放。

## 验证与边界

- `node tests/run.cjs`：194项通过，新增9项覆盖逐实例归属、过量伤害、混合未标记来源、历史快照、战报顺序与幂等、密集击杀预算、粒子复用、震动/点光上限及武器详情暂停。
- `node analysis/browser-smoke-combat-ui.cjs`：真实Chrome页面验收，桌面1440×900，手机360×800、DPR3，并检查320×740、390×844、844×390布局。覆盖触摸摇杆/冲刺、逐槽战报、保存/恢复、胜利与失败结算。
- 50只小怪同时被击杀的场景中，全部结算500有效伤害；两把同名武器各250，其余四把为0。桌面记录24个粒子、3个命中效果；手机12个粒子、2个命中效果，普通暴击点光和镜头震动均为0。
- 输出、截图和源码SHA-256见`artifacts/combat-ui/`；统计为本机软件WebGL验收，不代表真实手机帧率，尚未覆盖不同手机GPU的持续实机性能。
- 早期五波基准已适配战报阶段；旧平衡报告的数值仍只对应各自源码指纹。本轮不据此宣称整局难度或真机性能已全面通过。
