## 设计方向

当前难度作为难度1保留。截图中第17波已有多把最高品质武器、24件饰品、396晶币，说明下一阶段的问题主要是成长内容和选择空间不足。单纯增加物品数量会稀释商店，单纯增加品质会再次推高数值；本方案通过核心、攻击机制、专武契约和有限分支形成更多打法。

保持当前游戏的3D体素画风：方块角色、像素纹理、环绕武器、俯视场景和清晰鲜明的战斗表现继续保留。原创内容仍使用这套视觉语言，不改成写实、厚重工业或其他全新画风。

在现有画风内采用独立的奇境题材，工作名暂定《余烬回路》：玩家是探索失控设施的巡行者，敌人是异变构装和环境生命。道具使用机械零件、测量仪器和维护用品的语汇；场景内容可用炉庭、鸣砂区、雾渠、镜井。正式项目名称在制作品牌时再定。题材与名称调整不要求推翻现有渲染、材质、相机或整体配色风格。

不延用现有跨作品标题、职业称呼、专有武器名、Boss名称、辨识度强的轮廓、武器图标、台词和界面宣传文案。原创化不只换名字：标志性的眼球冲锋、王冠胶体、飞剑阵等也需要重新设计行为与视觉。程序化素材仍需按新设计重做，不能因为是代码生成就保留原有辨识造型。

## 难度与波次

### 难度1～5

开局选择难度，默认难度1；清除当前最高难度第20波，解锁下一档。本局开始后不可更换难度。难度解锁属于局外记录，武器和属性收益不带入下一局。

| 难度 | 普通怪/精英/Boss生命倍率 | 初版附加变化 |
| --- | ---: | --- |
| 1 | 1.00 | 当前1.7经济、玩家基础属性与操作时序作为基准 |
| 2 | 1.25 | 无 |
| 3 | 1.55 | 无 |
| 4 | 1.90 | 无 |
| 5 | 2.30 | 无 |

只在生成敌人时乘一次难度倍率，不给精英或Boss重复相乘。首版不同时提高伤害、速度、怪物数量、商店价格或减少收益，避免多条压力曲线叠加。死亡结算、战斗记录和测试报告必须显示难度。

新Boss的生命按出场波次决定，不能跟着Boss种类固定。第5/10波先保留1500/6000两个难度1基准；第15/20波暂拟10500/15000，只是待测试锚点。不同Boss可在0.90～1.10范围内校正生命，以弥补可攻击时间差异；不得用长时间无敌再叠加高生命。

### 主流程与无尽

- 正式挑战改为20波，第5、10、15、20波均有Boss，击败第20波后结算胜利，可继续无尽。
- 无尽每5波仍出现Boss。第25波起，每完成5波，普通怪生命在波次基础值上额外乘1.12，Boss相对第20波锚点每轮乘1.22，作为初稿，不无限发放新伤害乘区追平。
- 首版保持非Boss波的当前时长、刷怪预警和场内上限。Boss波仍刷普通怪，倒计时归零停止普通刷怪，必须击败Boss才能结束。
- Boss击败后允许继续完成剩余波次时间，奖励只在该波结算时打开，沿用当前流程，避免领奖时场上继续运行。
- 第10波不再弹出通关结算；所有“需击杀Boss”“倒计时决战”“死亡不能领奖”的判断统一使用`wave % 5 === 0`。

## 第5波主核心

核心从3种固定选项改为12种候选中的随机3选1，本局最多选一种。核心改变输出结构和操作取舍，不增加武器槽，不提供没有代价的大幅全局倍率。

第5波结算顺序为：未处理的普通宝箱 → 升级 → 核心3选1 → Boss专武选择 → 商店。Boss本身不再生成宝箱实体；其他来源的宝箱保留。

### 随机规则

1. 使用本局独立奖励种子，生成并保存3个不同核心ID。重新打开面板不会重抽。
2. 从具有至少一把当前已装备适配武器的核心中，随机取1款；不足时显示明确的适配解释，不给无效保证。
3. 第二款从第6波前可买到适配武器的核心中取，第三款从其余已实现核心中取。避免3款都是同一种输出结构。
4. 显示当前适配武器数、可购买的目标武器、正收益和代价；不只写“增加弹幕”等模糊说明。
5. 不提供付费无限刷新。可以“暂不选择”，后续每5波Boss结算时再提供随机3选1；一旦选定不再出现新的主核心选择。
6. 未持有任何对应武器的核心仍可以选择，用于转型，但不能以此直接赠送武器或提高品质。

### 选定后的商店

普通武器抽取权重拟为70%从核心适配池抽、30%从其他已开放池抽，先抽品质再抽种类，不跨品质抬高武器。每次进入新一波商店尽量提供至少1款可用的核心适配普通武器；这项保证不覆盖专武强化，也不保证最高品质。刷新使用同一权重，不重复触发进店保底。

### 标签与属性

在现有14项角色属性中新增“范围%”和“暴击效果%”，扩展为16项，保留6个武器槽，不增加新的独立伤害类型。伤害仍明确归入近战、远程、魔法；“领域、持续、连锁、构装、轨道、蓄力、返程、冲刺”属于机制标签，用于核心和道具匹配。

新羁绊使用刃械、弹道、回路、构装四个原创类别，仍为2/4/6件的最高档总加成，不逐档累加。新机制标签不自动生成另一套免费属性奖励。羁绊改名与重新配装时，应重新核算现有加成，而非叠加新旧两套。

## 用户补充规则：范围、升级与闪避

本节为后续实现的明确要求；与前文或旧版本记录冲突时，以本节为准。具体距离和比例是首轮调参起点，不表示当前1.7已经修改。

### 缩小武器基础范围，增加“范围%”属性

- 所有普通武器与Boss专武都缩小初始攻击距离和基础伤害覆盖，不能只缩小索敌而保留原来的大范围判定。已有武器首轮按1.7对应基础距离与伤害区域半径的70%起测；新武器在相同尺度下配置，模型、预警与碰撞同步缩小。不会因此缩小敌方技能或玩家冲刺距离。
- 新属性字段建议为`rangePct`，初始0，每1点表示相关距离增加1%。来源包括升级选择、道具和明确标注的核心效果；品质不再额外赠送范围。
- 范围同时影响晶币、红心和普通宝箱的拾取吸附距离，以及近战触及距离、远程索敌与有效射程。Boss奖励面板不属于场上拾取物。
- 拾取基础距离先按3.0世界单位起测，由范围属性统一修正；幸运继续影响随机奖励，但取消其额外扩大拾取距离的旧规则，避免同一收益隐含两条成长来源。
- 近战有硬上限，远程没有人为射程硬上限。按实际攻击组件分类，不按伤害属性分类：使用魔法属性的接触轨道仍执行近战上限，使用近战属性的投掷弹仍按远程距离计算。

| 生效对象 | 初稿计算 | 上限与边界 |
| --- | --- | --- |
| 拾取距离 | `3.0 × max(0.25, 1 + 范围% / 100)` | 不额外设置数值上限，不改变晶币面额和掉率 |
| 近战触及距离 | `缩小后的基础距离 × max(0.25, 1 + 总距离加成% / 100)` | 最终不超过该基础距离的1.75倍，且不超过6.0世界单位；两项取较小者，具体阈值待实测 |
| 远程索敌与射程 | `缩小后的基础距离 × max(0.25, 1 + 总距离加成% / 100)` | 无人为数值上限；竞技场大小和目标是否存在仍决定实际可命中距离 |

“总距离加成”包括角色范围属性及该武器适用的局部距离加成，集中计算一次。核心、道具、强化、校准均不能绕过近战最终上限。近战武器触及上限后，继续增加范围仍会改善拾取与已装备远程武器，面板需说明这一区别。

范围主要扩展攻击能够到达的位置：弹丸飞行预算、落点选择距离、陷阱部署距离、构装攻击距离等。范围属性本身不同时放大爆炸半径、领域面积、连锁跳距、扇形角度、构装数量和跳伤频率；这些仍由明确的专属效果改变，避免一项属性同时叠加射程与面积收益。缩小初始伤害覆盖与之后的范围成长分开配置。

轨道与接触组件采用近战距离上限；轨道角速度不随范围提高。部署物的部署距离和攻击距离可以各自读取一次角色范围，但不能把已修正后的数值再次乘范围。弹丸寿命和清理逻辑按实际飞行预算计算，不能用固定寿命暗中截断远程射程；实体数量和帧耗时约束仍保留。

范围列入角色、暂停、商店、升级和测试台面板。武器卡显示实际触及/射程，近战同时显示上限；拾取距离单独显示，不能只展示一个百分比让玩家猜效果。

### 升级只自动增加1点生命上限，保留属性选择

用户已确认保留升级属性选择。规则为：每升一级，自动增加1点生命上限，不自动增加攻击、攻速、暴击、护甲、范围等其他基础属性；随后仍获得一次现有四选一属性强化机会，选择生效后才增加对应属性。

- 属性选项仍可包含最大生命、三系伤害、攻速、范围等。选择生命选项时，所选生命奖励与自动的1点生命上限分别计算，明确显示，不误解为每级最多只能增加1点生命。
- 范围选项初稿普通档为+6%，较高档为+12%，数值待实测；其他选项沿当前升级预算逐项复核。
- 自动的1点生命上限先沿用当前同时回复1点生命的行为，不额外回满。连续升多级，每级各记一次自动生命和一次待处理选择，不合并漏发。
- 属性选择仍在波次结算时依次处理，不在战斗中弹窗；不改成自动选择，不把所有候选属性一起加给玩家。
- 升级刷新保留当前付费规则。升级本身不自动发武器、饰品、晶币或专武强化。

### 闪避默认上限60%，预留特殊上限接口

- 普通角色默认上限60%，实际闪避率统一为`min(当前闪避上限, max(0%, 所有来源汇总闪避率))`。普通攻击、Boss技能和敌方弹丸都使用同一入口，不能各自硬编码60%。
- 预留独立字段`dodgeCapBonusPct`，默认0，单位为百分点；当前上限=`clamp(60 + 合法上限修正之和, 0, 100)`。未来特殊角色和装备可显式提供上限修正，例如+5使上限变成65%；上限提高不等于同时增加5点闪避率。
- 普通的“闪避+X”只增加闪避率，不改变上限。只有明确声明“闪避上限+X个百分点”的角色/装备配置进入上限接口；当前目录没有默认赠送这类能力，难度不修改上限。
- 面板显示有效值和当前上限，例如“60% / 上限60%”或“65% / 上限65%”；移除特殊装备后立即重算。原始溢出值不提供额外减伤、反击或隐藏收益。
- 已达到当前上限时，升级不再提供纯闪避选项；接近上限时显示本次实际收益，例如默认上限下58%选择+5个百分点，实际只增加到60%。
- 仍可购买包含其他属性的复合道具，但必须提示其中闪避部分已经封顶。冲刺无敌与受击保护是独立状态，不作为突破闪避上限的概率计入。

### 全伤害属性上限50%

- 全伤害包括角色、道具、羁绊、升级和条件增益提供的同名属性，统一相加后取正向上限50%。`有效全伤害%=min(50, 全伤害汇总值)`；负值仍保留，最终伤害至少为1。
- I42低血量、I43高血量、I48对Boss硬直等作用于所有武器的条件伤害增益，也计入这50%的同一预算，不能改个名字再作为全局独立乘区叠加。
- 上限约束的是“全伤害”属性，不是把最终伤害限制为原来的1.5倍：三系固定伤害、暴击倍率和特定武器的独有效果仍按各自规则计算。特定机制奖励不得偷偷影响所有武器来绕开全局上限。
- 面板显示有效全伤害和溢出提示；达到50%后不再提供纯全伤害升级选项，接近上限时提示本次实际增加量。条件增益暂时被截断不返还资源。

### 暴击效果与溢出转化

- 新属性`critEffectPct`，中文“暴击效果%”，角色基础初始为0。0不表示暴击没有额外伤害；先保留1.7的基础暴击倍率1.75，暴击效果每1点额外增加0.01倍倍率。
- 最终暴击倍率=`max(1, 1.75 + 有效暴击效果% / 100)`。例如暴击效果+20%，暴击造成195%伤害，不是175%再乘1.20。
- 暴击效果拟进入升级候选，普通档+8个百分点、较高档+16个百分点，数值待实测。实际暴击率仍限制0～100%，暴击效果暂不新增硬上限，通过获取量与预算校准。
- 新装备I49“盈锋转换器”：当某武器的原始总暴击率达到100%后，超出100%的部分按2：1转成该武器的额外暴击效果，保留100%实际暴击率。这里按“溢出转化”解释，不把已经达到的100%暴击率扣走。
- 每把武器单独计算：`R=角色暴击率+武器自带暴击+合法条件暴击`；`实际暴击率=clamp(R,0,100)`；装备生效时`转化暴击效果=max(0,R-100)/2`。每次重新计算，不永久写回基础属性，也不把同一份溢出循环转化。
- 例：原始总暴击率100%→实际100%、转化+0；140%→实际100%、转化+20；180%→实际100%、转化+40。角色自有暴击效果为0时，对应暴击倍率为1.75/1.95/2.15。
- 先汇总原始暴击再转化，不能先截断100%导致装备失效。没有装备时溢出无额外效果；卸下装备或失去条件暴击后立即重算，不能保留旧转化收益。
- 本装备不让DOT、核心回声、额外连锁等原本不能暴击的伤害获得暴击；由可暴击主段生成的衍生伤害，按未暴击主段预算计算，不把暴击先放大后再衍生一次。

### 优化后的16项基础属性

以下是无职业、无装备修正的角色基础值。职业仍可有明确的初始差异；等级只自动改变生命上限，其他属性必须由选项或装备等合法来源改变。

| 属性 | 字段 | 基础初始值 | 主要作用与边界 |
| --- | --- | ---: | --- |
| 最大生命 | `maxHp` | 25 | 决定生命容量，每级自动+1，最低1 |
| 生命再生 | `hpRegen` | 0 | 按战斗时间缓慢回复生命 |
| 吸血触发率 | `lifeSteal` | 0% | 合格命中触发回复；概率最多100%，回复仍受每秒最大生命5%的共享上限 |
| 全伤害 | `dmgPct` | 0% | 全局伤害修正，正向上限50% |
| 近战伤害 | `meleeDmg` | 0 | 按武器系数提供固定伤害，不等于近战范围 |
| 远程伤害 | `rangedDmg` | 0 | 按弹道武器系数提供固定伤害，不等于射程 |
| 魔法伤害 | `magicDmg` | 0 | 按回路/法术武器系数提供固定伤害，不额外增加领域面积 |
| 攻击速度 | `attackSpeed` | 0% | 缩短指定主攻击时钟，不能同时加速部署与部署物射击 |
| 暴击率 | `critChance` | 5% | 角色提供的暴击率；叠加武器自带值后实际最多100%，I49读取未截断溢出 |
| 暴击效果 | `critEffectPct` | 0% | 增加基础1.75倍之上的暴击倍率；属于新增基础属性 |
| 护甲 | `armor` | 0 | 降低受到的伤害，负值增加所受伤害 |
| 闪避率 | `dodge` | 0% | 避免合格敌方命中，默认上限60%，特殊上限接口独立配置 |
| 移动速度 | `speed` | 0% | 修改角色基础移动速度，不自动增加冲刺无敌时间 |
| 范围 | `rangePct` | 0% | 修改拾取、近战触及和远程攻击距离，近战封顶、远程无硬上限 |
| 幸运 | `luck` | 0 | 影响奖励品质和随机掉箱，不再隐含增加拾取范围 |
| 收获 | `harvesting` | 0 | 波末发晶币并保留小数成长，不提供经验 |

“闪避上限修正”是角色/装备的特殊规则接口，不是第17项常规基础属性，不进入普通升级随机池。基础暴击倍率属于战斗规则，也不单独增加一个面板属性。角色面板显示通用值，武器详情展示包含该武器自带暴击与I49转化后的实际暴击率/倍率，避免两者混淆。

### 武器独有效果

在内容目录补充F01～F12共12个效果提案，分别绑定指定武器实例，围绕连刺、蓄压过杀、腐蚀传播、构装专注、返程等形成差异。它们是对原始攻击机制的细化或替换，不是每把武器白送第二套额外伤害。预算、触发频率、归属、暴击资格、范围上限与衍生不递归规则都需逐项校验。

## Boss随机与专武契约

### Boss出场

采用洗牌袋：将所有已实现Boss打乱，依次取出；袋空后重新打乱，不能让上一袋最后一位紧接着重复。完整6位后，单局前6次Boss互不重复，既随机又避免总见同一位。首包只有3位时仍沿用相同规则。

Boss身份在该波开始时确定并写入记录，不能在重开面板时抽取。上一波商店展示下一位Boss名称及一条应对提示，不公开整套未来顺序。

所有Boss均可在第5波出场，低波次限制弹幕数量和技能组合；不能因为抽到某位复杂Boss就遇到高波次专用连招。其原始技能伤害以当前史莱姆王/眼球的14、18、22为参考，逐Boss实测，不按名字固定高伤害。

### 奖励与商店资格

Boss不掉宝箱，改为本局首次击败该Boss后提供对应专武。保留当前20晶币奖励，不同时额外发饰品、宝箱或材料。

| 玩家状态/操作 | 结果 |
| --- | --- |
| 选择“保留并装备”，有空槽 | 专武进入一个正常武器槽；建立本局强化资格 |
| 选择“保留并装备”，6槽已满 | 展示替换对比；确认替换后，旧武器按正常售价返还一次，再装备专武 |
| 返回替换列表 | 只返回奖励选择，不改变装备或解锁记录 |
| 选择“放弃本次奖励” | 不发补偿晶币，不开出强化，不修改已有专武 |
| 之后出售或替换掉专武 | 立即移除该实例的强化资格；对应锁定强化卡也失效并被替换 |
| 之后再次击败该Boss，当前未持有专武 | 可以再次决定是否保留；先前放弃不等于永久封禁本局 |
| 再次击败Boss且已持有其专武 | 提供一次该专武的分支重配，保留强化等级；放弃不会删除旧专武或其强化资格 |

强化资格是“当前装备中实际保留了专武”，不是永久收藏解锁。首版没有背包或额外专武槽；每款专武最多持有1把，不进行复制合成。选择奖励要校验阶段，防止重复点击重复装备、返款或解锁。

### 专武强化

> 2026-11-15设计更新：[Boss专武专属属性与核心共鸣设计](Boss专武专属属性与核心共鸣设计.md)为X01～X03后续实施依据，新增独有资源、两条机制路线与指定核心共鸣，并以常驻改装入口替代随机强化卡。下列随机投放等内容保留为旧方案记录；与新稿冲突时采用新稿。现有三把已在1.10实装，参见[v110实施记录](history/v110-实施记录.md)；新稿中的后三把仍为后续设计。

- 专武使用固定的“专属”品质，初始效能按普通II阶预算设计，波次和Boss种类不会再次乘品质倍率。
- 每把专武有0～3级强化。每级二选一，分别偏单体与群体/控制；升级后沿用该分支，后续重复Boss可进行一次分支重配。
- 单把专武3级强化的纯单体DPS增益合计上限先设30%，其他收益放在覆盖、可靠性或条件效果，禁止每级叠加额外攻速、暴击、穿透和完整基础伤害。
- 四格商店中，专武强化最多占1格，替换弹性商品格，不能挤掉两格普通武器保障。初稿进店/刷新出现率25%；连续3次新商店未出现且有可强化专武时，下一次新商店保底。该计数不被刷新推进。
- 多把专武时，从可强化者中轮换，优先较低级；当前卡固定目标实例ID，不能买A的强化给B使用。
- 强化基价依等级为32/48/68，再乘当前商店价格系数和波次涨价。强化明确收费，不是免费材料。
- 强化满级后停止投放对应强化。普通刷新和幸运不突破强化等级上限，也不重置分支。

## 无尽模式的成长空间

扩大内容池的同时控制重复和数值膨胀：

1. 普通品质开放改为I阶第1波、II阶第3波、III阶第8波、IV阶第14波。商店按下一波计算。合成也遵守当前已开放上限，点击前明确提示何时开放，不把两把武器先扣掉。
2. 保留4阶上限，不继续添加V/VI/十阶。品质仍主要提高伤害，不能每升阶再增加攻击频率和免费多弹。
3. 49款道具分批开放，最高持有量按内容目录限制。达上限后从候选池移除；同一次商店不重复同一ID，优先填入其他合格候选。
4. 第12波起开放后期交换道具，第20波后按需投放“校准方案”：每把IV阶普通武器最多装1个，只能替换，不能无限叠加。例如窄角聚束与宽角散射互斥；替换前展示同一目标下的输出和覆盖变化。
5. 校准是换取打法，不是无限等级。候选池无合法新选择时允许出现普通商品或有限的治疗服务，不用超额属性填空。局间已自动回满生命时不出售无效治疗。
6. 将武器实例的品质、专武强化和校准拆开；普通合成不复制校准、触发次数或专武资格。重复购买、卖出再买入不能重置“本局一次”效果。

## 共用的战斗约束

- 所有额外弹、领域跳伤、连锁、持续、构装、核心回声均记录来源。伤害统计分别显示主武器和衍生机制，不因多段攻击重复累计释放命中率。
- 每次释放按总命中预算设置属性系数。散弹3枚不等于每枚都吃完整远程属性；持续每跳不重复吃完整魔法属性。
- 区分“武器主机制输出”和“额外衍生伤害”：构装正常射击属于主机制，DOT仅启用持续伤害专用规则；额外连锁、碎裂、回声等标记为二级来源，不能再触发连锁、爆炸、召唤或回声。构装和DOT不触发额外金币、经验。
- 同一伤害事件不能重复吸血；全局每秒最大生命5%的吸血上限继续有效，回复和护盾不触发自身。
- 减速最多40%，定身Boss免疫；对Boss控制改为减速折算且最多15%，不延长硬直或阻止技能。
- 攻速只作用于一种主时钟：构装的射击或武器部署二选一，不能同时缩短两者造成平方增长。冷却下限仍需逐机制校验。
- 预警面积与真实判定一致；暂停停止技能、陷阱、DOT、召唤、内置冷却和护盾衰减。清场回收全部预警和挂载实体。
- 首包目标上限：每玩家构装6个、陷阱12个、友方领域8个；超过上限按最旧实例替换，不多扣钱。效果批量更新，限制同屏伤害文字，记录帧耗时。

### 平衡验收

- 难度1第5波Boss目标15～25秒，强构筑可更快，弱构筑可更慢；记录每位Boss可攻击时间和玩家承伤，不能只用血条长度比较。
- 第10/15/20波分别以正常换装预算测试，目标Boss约20～40秒，不用“固定一套初始武器打到底”代表所有构筑。
- 每个核心至少测试2种适配构筑、1种混搭；同预算单体与群体分别对比。异常超过同档中位数约25%时检查覆盖和代价，不自动把所有武器削到一样。
- 分别测试保留、放弃专武：放弃后零专武强化卡；出售后下一次渲染即清除无效锁定卡；满级后不占空强化卡。
- 记录前五波晶币来源、购买、饰品数量、武器品质和Boss耗时，防止内容扩充重新制造1.7之前的经济溢出。
- 难度倍率、随机袋、奖励持久化、同种专武限制、触发链、冷却和性能均进入验收；各项实际验证状态以实施记录为准，不能由本方案推定全部通过。
- 分别测试范围为负、0、高正值时的拾取/近战/远程效果；近战所有加成路径均被上限限制，远程不被固定索敌半径或寿命截断，伤害图形与判定一致。
- 连升3级应只自动增加3点生命上限、产生3次属性选择；未选择前其他属性不自动改变。选择生命可再加生命，选择范围只影响约定的距离。
- 闪避汇总为59%、60%、超过60%、受负面属性影响时均验证判定和面板一致；模拟特殊角色/装备将上限升至65%并移除，验证当前上限重算，普通闪避加成不能修改上限。
- 全伤害49%、50%、超出50%与负值均校验，条件全局增益不能绕过上限；确认暴击和明确的单武器效果仍按各自规则计算。
- I49分别测试原始暴击率99/100/101/140/180%、不同武器自带暴击、临时条件失效、卸装与重复重算；基础暴击效果0，140%原始暴击在无其他效果时应得到100%实际暴击与1.95倍倍率，不能重复转化。
- 新旧内容同屏比较确认体素、像素纹理、俯视构图和清晰配色保持一致；原创化不等于更换游戏画风。
