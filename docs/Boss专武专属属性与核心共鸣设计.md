# Boss专武：专属属性、强化路线与核心共鸣

日期：2026-11-15。状态：X01～X03已于1.10实装，验证与主动数值修正见[v110实施记录](history/v110-实施记录.md)；X04～X06仍为后续设计。本稿重做现有X01～X03；覆盖此前这三把专武共用“聚焦每级+8%／广域每级+3%及覆盖+12%”的目标设计。当前实际行为仍以武器图鉴为准。

## 设计目标与共用规则

专武应有“无需强化就能看见的招牌机制”，选定核心后改变打法，强化再发展为两个方向。无需匹配核心也应有保留价值，不以大幅增加常驻全局属性制造存在感。

1. 保留16项角色基础属性。新增的是武器面板中的专属参数与资源条，只作用于该实例，不增加幸运、收获、闪避或全局伤害。
2. 0级即有完整招牌动作；1级确定路线、2级改变节奏或目标规则、3级完成形态。取消旧共用百分比强化，不和旧加成叠加。
3. 一局仍只有一个主核心。专武命中指定核心时，执行专属“共鸣规则”，替换该专武的通用核心规则；其他武器仍用通用规则。不能先吃一遍通用多弹，再复制整套专属招式。
4. 下文数字为无额外属性、无羁绊、0级的原型基准，初始专武不再乘II阶品质倍率。实际实现需先生成一次属性预算，再按比例拆分，不能每针、每跳再吃一遍完整属性。
5. 原生主击可以暴击和按全局规则吸血；冲击追加、协同追加、回收伤害、棱面和闭环脉冲不可暴击、不吸血、不产生触发递归。全部伤害只应用一次有效全伤害，仍遵守50%上限。
6. 储量按一次原生释放组计数。多目标、双针、多蜂、分流和返程重复命中不能重复充能；道具、箱子、衍生攻击不充能。伤害型充能要求实际伤害大于0。
7. 冲击与协同储量开波清零；连续6秒没有有效原生命中后每秒减少20，最低0。出售、替换、重配路线均清空储量与该实例挂载实体，不通过重装获得免费齐射。
8. 初版目标：新版0级在正常获取预算下与适配的II阶普通武器有竞争力；同核心、同属性下，3级相对新版0级的稳定单体DPS提升控制在30%以内。跟随带来的攻击覆盖时间、命中率、控制和范围同样要计入强度评估。

## X01 断响铰锤——积蓄后打出重击

定位：靠近、积压、重击，玩家能预判下一次爆发。强化改变主击与震波的分配，不靠不停提高攻速。

### 专属属性：冲击储量

| 参数 | 初始设计 |
| --- | --- |
| 冲击储量 | 0～60，每次原生主击有效命中+20，一次释放最多加一次 |
| 普通攻击 | 主击24＋延迟震波8，周期1.30秒；蓄力0.65秒，震波延迟0.55秒 |
| 招牌动作“断响重震” | 第三次有效主击达到60时，立即消耗60，将本次震波8替换为24；不是另加一轮完整攻击 |
| 强震表现 | 三段锤芯依次点亮；满储重击出现厚白刃缘、橙色断层与一次明显的落地环 |
| 基准预算 | 三次完整命中为32＋32＋48＝112；强化震波部分不可暴击 |

普通与强化震波初始半径均2.24，强震主要强化视觉与单次冲击，不免费扩大范围。近战触及上限保持，裂缝伤害形状在本次释放原点6.0单位内裁剪；移动后不重新延长已释放攻击。普通怪可被击退，Boss不强制打断技能或延长硬直。

### 强化路线

| 等级 | 聚砧：集中爆发 | 裂地：范围控制 |
| --- | --- | --- |
| 1级 | 强化震波24→30，半径2.24→1.60，集中打单体 | 震波半径2.24→2.60，强化震波24→20作为代价 |
| 2级 | 强震落点优先锁定本次主击命中的精英/Boss位置；只在释放时锁点，延迟期间不追踪；不增加触及距离 | 强震变为三道扇形裂缝，总伤害20分为7/7/6；同目标合计不超过20 |
| 3级 | 强化震波30→36；原生主击仍24，普通震波仍8 | 三道裂缝总预算20→24，各8；形状更宽，普通怪减速20%持续0.6秒，Boss最多15% |

聚砧3级三次基准预算为32＋32＋60＝124，相对0级112增加约10.7%；更可靠的锁点收益仍需实测。裂地以覆盖和控制换取强度，不另叠旧路线的+9%伤害和+36%半径。

### 指定核心的独特共鸣

- **重锤协议 → 砧心崩击**：保留主击×1.25及周期×1.20；将本次震波预算并入近身落锤，取消远处延迟波。普通为主击30＋冲击8，满储为主击30＋冲击24；只有原生主击部分可暴击。强化分支先确定震波预算，再进行转移，不能既打落锤又在远处打同一份震波。聚砧偏单体；裂地改为脚前扇面冲击，仍共享预算。
- **滞爆协议 → 十字断层**：普通震波执行半径×1.35、震波预算×0.90、延迟+0.20秒；满储时改为四向裂缝。0级强化震波24经减伤取整为22，分配6/6/5/5，同目标合计最多22。与裂地分支组合时采用四向形状，不再额外生成三条旧裂缝。
- **蓄压协议 → 携压突进**：保留满蓄预算×1.35、蓄力时间×1.30和普通移动代价。冲击已有两格、第三锤蓄力就绪期间冲刺，可将本次落锤移到冲刺终点执行；本次冲刺不再造成默认冲刺伤害，改由落锤结算，武器冷却不重置。不冲刺时仍可正常自动释放，避免依赖额外操作才能使用。

## X02 簇砂蜂巢——持续陪伴的蜂群

定位：从“另一台固定哨机”改为可辨识的跟随砂蜂。它持续跟随玩家、参与集火，通过可见的协同齐射形成存在感。

### 专属属性：协同储量

| 参数 | 初始设计 |
| --- | --- |
| 单位 | 1只跟随砂蜂，保持约1.5～2.0单位随行距离，移动和转向有速度上限，不瞬移追杀 |
| 持续与射击 | 持有期间持续存在，不再用4秒存在/6秒重部署；射击间隔改为0.75秒，双针总伤10，分5＋5 |
| 协同储量 | 0～100；一组原生双针至少一针对活敌造成有效伤害后+20，同一释放组最多计一次，击杀也计入 |
| 招牌动作“协同齐射” | 达到100的本次射击增加四枚协同针，总附加预算10；原生双针10＋协同针10＝20，随后清空 |
| 资源表现 | 玩家身侧五枚蜂灯逐格点亮，齐射时展开六路针迹；普通双针与协同追加用两种颜色区分 |

协同针的基准整数预算为3/3/2/2，不暴击、不吸血。蜂群只攻击射程内目标，不全场索敌；远程射程继续受范围属性影响。基准五组齐射总伤为10×5＋10＝60，平均原始单体输出约16/秒；需把持续跟随、转向和攻击机会一起测试，不能只看单针10比旧12低。

### 强化路线

| 等级 | 聚猎：追踪集火 | 播簇：分散与牵制 |
| --- | --- | --- |
| 1级 | 优先精英/Boss；双针命中后标记3秒，协同针有限转向追踪标记者，不穿越场地边界 | 协同针可分配给最多3个目标，总附加预算仍10，不能每目标各发10 |
| 2级 | 每组协同获取20→25，四组有效双针即可齐射 | 由1只母蜂改为2只幼蜂，共享同一射击组、储量及总预算，不因此翻倍伤害 |
| 3级 | 协同附加预算10→14；原生双针总预算仍10 | 齐射后在蜂群位置留下1处半径1.2的砂网0.6秒，仅减速20%、不伤害；每3秒最多一次，Boss减速最多15% |

聚猎3级平均每四组预算为40＋14＝54，平均13.5/组，对0级平均12/组约增加12.5%，追踪可靠性额外验收。播簇用目标分配和控制体现成长，不用额外金币、免费护盾或无限召唤补偿。

### 指定核心的独特共鸣

- **机巢协议 → 双蜂牵线**：最多2只蜂，两蜂合计使用原单蜂120%的原生与协同预算，射程-15%；不是两蜂各120%。协同满值后，追加预算改沿两蜂之间的连接线结算一次，可分配给最多3个敌人，总追加预算不变。单体可收到原生主击与一次协同追加，但不能被两条复制的线重复伤害。播簇2级已有双蜂时不再加成4只；所有构装全局6单位上限不变。
- **分流协议 → 绽针散网**：原生射击变为两组轻分叉双针，每组60%预算，射击间隔+15%；协同齐射改为三个小扇面，追加预算同样只使用一次分流后的总量。普通射击基准总预算12，满协同时原生12＋追加12＝24，不再给每个扇面复制完整齐射。贴近可以集中，远处分散覆盖，协同仍只按一组成功原生双针计数一次。

固定哨机作为普通武器继续存在，跟随蜂不只是换皮固定哨位。未来回声核心上线时再设计其第三种共鸣，当前不把未实现核心作为必需条件。

## X03 分束棱核——回收空路的折射武器

定位：群怪时连导，单Boss时回收没用掉的连锁预算。解决“Boss附近没有杂兵，专武大半机制直接失效”的问题。

### 专属属性：空路折射率

| 参数 | 初始设计 |
| --- | --- |
| 原生预算 | 主束14＋第一跳7＋第二跳4，周期0.85秒，跳距3.0 |
| 空路折射率 | 初始60%，仅回收本次原生预算中未找到合法目标的部分 |
| 招牌动作“空路回收” | 无后续目标时，未使用的7＋4按60%取整为7，回到主目标；总伤为主束14＋回收7＝21 |
| 有目标时 | 跳到一个敌人后，剩余4按60%回收2；完整命中三个不同目标则不再回收 |
| 表现 | 未用棱片从武器两侧收回，汇成一束白芯补射；实际跳跃显示路径，回收与暴击颜色不同 |

回收只能结算一次，不暴击、不吸血、不重新连锁。主目标在结算前死亡则回收作废，不把过杀伤害再次传递。分流两束共享一张“预算账本”，不能各回收一次。

### 强化路线

| 等级 | 聚束：单体收束 | 折域：路径与覆盖 |
| --- | --- | --- |
| 1级 | 空路折射率60%→80% | 跳距3.0→3.6，折射率60%→40%作为单体代价 |
| 2级 | 将原生第二跳的4点预算转入主束：主束18＋一跳7，不额外保留被取消的第二跳 | 原生第二跳4拆成两个新目标各2，总预算不变 |
| 3级 | 折射率80%→100%；单Boss基准总预算18＋7＝25 | 跳距3.6→4.0，折射率40%→50%；路径可借道1个已命中过的节点寻找新目标，但不再次伤害该节点 |

聚束对单Boss基准21→23→24→25，3级较0级约增加19%；完整群体预算仍为25。折域保留覆盖取舍，不让一个目标重复吃多条完整连锁。

### 指定核心的独特共鸣

- **导弧协议 → 闭环电网**：替换原通用“主伤-15%＋增加一跳”规则。由分支处理后的主束预算取15%、第一跳预算取15%，取整后转为一次闭环脉冲；余下预算仍用于原生主束和跳伤。0级示例为12＋6＋4＋闭环3，合计25。脉冲沿本次路径围成的区域结算，最多3个新目标分摊预算；已被本次原生连锁伤害的敌人不能再吃脉冲。没有可伤害目标的脉冲预算进入同一次空路回收，不循环创建新脉冲。
- **分流协议 → 交叉棱面**：替换通用60%双束规则，主束预算平分成两侧夹击射线，周期+15%；原生末跳预算改在交点形成0.6秒棱面。若聚束2级已经移走末跳，则从剩余连锁预算提取25%给棱面。棱面预算只能消耗一次，最多3个尚未被本次释放伤害的新目标分摊；无目标时按折射率回收。两束共用剩余跳数和回收账本，不各生成一套棱面。

共鸣与分支顺序固定为：品质/属性预算→分支预算转移→核心共鸣重新分配→整数分段→实际命中→一次空路回收。总预算被转移后不能在旧节点再次使用。

闭环路径不足三个不同节点时不生成区域，脉冲预算直接进入同一次空路回收。折域2级拆出的两个末跳子节点共享原末跳预算；交叉棱面取走这份预算后，两个子节点均取消，不能同时保留伤害。

## 让玩家更容易实际体验到路线

1. 第5波结算改为：普通宝箱→升级→专武预览及保留/替换→核心3选1→商店。保留专武时，至少一款它的已实现共鸣核心进入候选；另外保留当前普通武器适配和转型空间，不强制选择该共鸣。
2. 后续Boss奖励先展示与当前核心“已共鸣/未共鸣”。未共鸣也展示招牌机制，避免把武器误当成无效掉落；不因此免费更换已经确定的主核心。
3. 商店增加始终可见的“专武改装”入口，取消旧25%随机强化卡及保底计数；普通四格商品保留。每次新进商店最多购买一次改装，所有持有专武共享次数，刷新不重置。
4. 首版价格沿用当前32/48/68基价及商店波次系数，先改善可见性而不同时免费提高强化收入；如实际经济支持不了路线再按实测调整。
5. 首次购买选路线，之后按路线升级；再次击败同款Boss仍可免费重配并保留等级，但清空专属储量。出售撤销服务资格，重新获得是新实例0级。
6. 专武奖励卡展示原生动作、专属属性、一次招牌动作预演，以及当前核心会产生的变化。强化卡展示“本级具体改变什么”和代价，不只写伤害百分比。
7. HUD只为已持有专武显示紧凑的冲击格、蜂群灯或折射率；充满时一次音效/边框闪烁，不持续盖住敌方红色预警，不新增全屏震屏。

## 其余三把专武的方向（后续包）

| 专武 | 独有属性与招牌机制 | 优先设计的核心共鸣 |
| --- | --- | --- |
| 蚀潮喷管 | 蚀压：同源持续附着到期释放一次受预算限制的泄压，不因刷新无限爆炸 | 熵蚀延长附着并迁移剩余预算；霜凝将泄压转为碎霜控制；滞爆改变区域形状 |
| 时序闸枪 | 时序偏差：保存一次原生束流的旧落点，冲刺可重定位下一次迟束，不复制整次释放 | 蓄压将即时与迟束预算重新分配；疾行改变迟束落点；回声只复写迟束的有限部分 |
| 偏轨轮毂 | 归航势能：轨道接触与回收共用预算，主动回收改变下一轮相位 | 归航增强返程并削减接触预算；轨道改轨距/相位；疾行在冲刺终点重新布轨 |

以上三把需对应Boss与共用组件先完成；表内不提前承诺已验证数值，不进入当前随机池。

## 实施与验收

1.10已按预算/资源接口→三把零级机制、两路线、共鸣与UI→奖励顺序与改装服务完成本轮实施。以下为验收规则，实际通过情况及长期验证边界见v110实施记录。

- 测试无核心、适配核心与不适配核心；同一核心下0/1/2/3级分别测单Boss、5目标、混合移动目标。
- 单体理论与实战均要计入跟随、转向、延迟落空、核心周期代价和强化费用；达到30%上限后优先调整分配，不增加隐藏乘区。
- 强震替换不能同时保留旧震波；双蜂不能双倍充能；分流不能复制齐射或回收；回收、闭环和棱面不能循环触发。
- 三针/双针/裂缝按同一预算整数分摊，所有分支和共鸣组合都验证总量守恒；主击与衍生的暴击资格分开。
- 近战触及、闪避60%、全伤50%等用户规则保持；特殊控制不延长Boss硬直或造成永久停顿。
- 暂停/图鉴、出售、满槽替换、重配、清场、20波继续奖励、改装次数跨店与刷新均要回归。
- 实机体验目标：取得0级专武后数秒内能识别招牌机制；1级看得出路线、2级改变战斗节奏、3级表现完整。规则回归与浏览器流程已验证；可识别性和完整对局体验仍需真人反馈。
