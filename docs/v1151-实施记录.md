# 1.15.1 商店锁定与发布整理

日期：2026-11-19。

## 修改

- 武器与饰品统一显示锁定状态。未锁定为灰色提示及“锁定”按钮；锁定为金色外框、金色状态条和“取消锁定”按钮，保留品质边框。
- 状态条说明刷新及下次商店保留的效果，按钮通过 aria-pressed 提供按下状态，支持键盘焦点，手机最小点击高度为44像素。
- 拒绝对已购买、已失效、非普通商品或异常索引执行锁定。商品生成与价格规则保持原有行为。
- 基于当前版本重写 README，更新启动、操作、构筑、锁定、手机适配与测试说明，加入本轮手机横屏战斗截图；移除已过时的视觉表现、快捷键与许可声明。
- 产品HTML固定使用LF换行，避免Windows和其他平台检出后生成不同的源码指纹。

## 验证

- `node tests/run.cjs`：203项通过，含武器及饰品锁定、刷新/下次商店保留、取消后替换与无效操作保护。
- `node analysis/browser-smoke-v1.15.1.cjs`：本机 Chrome 验证真实DOM点击、状态样式、刷新保留、存档恢复、桌面和手机布局，报告见 `artifacts/v1151/browser-smoke.json`。
- 手机截图使用844×390横屏视口、触屏与移动设备上下文，由游戏实际渲染生成。战斗场景使用脚本配置第8波及一组敌人，未改写截图像素。
- 软件WebGL截图用于检查布局和效果，不作为实体手机性能结论。

保留此前武器成长、全拾取、范围与镜头、槽位伤害、低闪击杀反馈及Boss成长修改，作为本次发布的当前项目版本。
