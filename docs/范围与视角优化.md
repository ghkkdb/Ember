# 范围与视角优化

更新日期：2026-11-18，基于1.13.0继续调整。

## 武器范围

- 全部42款武器的基础可达距离由配置值×0.70提高为×0.98，相比调整前增加40%。品质不再额外改变范围。
- 近战世界上限6→8.4，保留基础范围×1.75的属性加成上限；挥扫有效判定仍为索敌距离×0.85。混合武器远程段独立计算射程。
- 领域、陷阱感应与爆炸、落星、普通及专武轨道、连锁与分弧、印记爆炸、冲刺短杖震波、回收爆发和专武延迟刻痕半径同步扩大40%。铰锤震波释放原点裁剪改为8.4。
- 判定、领域预热、陷阱感应环、轨道位置及图鉴说明随对应参数更新。拾取范围、敌方攻击和构装数量限制保持既有规则。

## 默认镜头

- 默认微倾2.5D，透视镜头高度29→40，后移距离17→23.5，垂直视场角保持36度，维持原有倾斜观感。
- 初始化、切换、持续跟随共用相机预设，窗口缩放更新画幅；1440×900下相同屏幕采样点对应地面跨度约增加38%。
- 旧版未带视角偏好版本的俯视设置迁移为微倾，旧版固定/微倾选择保留。旧数据无法区分默认俯视与手动俯视；本次迁移后二者统一改为微倾，可随时重新选择俯视。
- 设置面板和V键切换都会保存明确选择；带新版偏好标记的俯视不会再次迁移。
- 地砖远景采用多级缩小采样，近景保留最近邻放大，减少抬高镜头后的纹理摩尔纹。
