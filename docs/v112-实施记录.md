## 二、详细技术实装

### 1. 12 款主核心协议与双向适配 (`CORE_RELICS`)
- **return（归航协议）**：所有非近战弹道具备自动回弹与二次引爆能力；惩罚：弹丸飞行速度 -15%。
- **orbit（轨道协议）**：生成围绕英雄环绕的护身能量体，提供近身防御与持续周遭伤害；惩罚：攻击速度 -10%。
- **dash（疾行协议）**：冲刺后 1.5 秒内下一次攻击暴击率 +50% 且暴击效果 +25%；惩罚：常驻护甲 -2。
- **echo（回声协议）**：释放技能或重型攻击后在原地留下残影共振，2 秒后释放 40% 威力回响；惩罚：全伤害 -10%。
- 实现了与现有武器、首领专武共鸣系统的双向适配检查机制（`coreFits`）。

### 2. 6 位 Boss 与 6 把 Boss 专武闭环
- **tank（潮蚀容器）**：三技能为 `高压水炮`、`酸液喷溅`、`高压潮涌`。对应专武 `boss_tank`（蚀潮喷管），具备腐蚀流道与扩散喷头双分支，与 `frost`、`entropy` 核心产生强共鸣。
- **clock（逆相钟匠）**：三技能为 `时序齿轮`、`齿轮逆旋`、`发条爆炸`。对应专武 `boss_clock`（时序闸枪），具备重摆擒纵与发条蓄力双分支，与 `charge`、`echo` 核心产生强共鸣。
- **train（灰穹列车）**：三技能为 `铁轨铺设`、`撞击冲锋`、`蒸汽轰击`。对应专武 `boss_train`（偏轨轮毂），具备撞击偏角与多重脱轨双分支，与 `heavy`、`return` 核心产生强共鸣。
- **程序化 3D 体素模型与预警**：为 3 位新 Boss 增加了体素构造及独立材质表现，并编写了专属出生预警与技能指示圈。
- **首领抽样保底**：`nextBossId()` 保障前 10 波从 3 个基础 Boss 中洗牌，确保早期教学与压测确定性种子（seed 11, 29）完美复现；10 波后全 6 位 Boss 参与洗牌。

### 3. 50 件道具全量落地与机制重构 (`ITEMS_DB`)
- 严格遵循 16 项 `STAT_META` 规范，杜绝非标准属性键。
- **应急密封（ankh_shield）**：开波自动获得生命上限 8% 独立护盾。
- **溢流蓄罐（celestial）**：满血或溢出治疗量的 50% 转化为护盾，单波上限 10% 生命上限。
- **断电保险（fuse_breaker）**：单局首次致命伤免疫，强制保留 1 点生命并触发 1.5 秒无敌保底。
- **滑移轴（slide_axle）**：冲刺冷却真实缩减 0.3 秒，保底冷却 0.6 秒。
- **无尽模式第 25 波起**：普通怪生命阶梯乘以 `1.12 ** Math.floor((wave - 20) / 5)`。

### 4. 多维伤害归属账本 (`hitTarget`)

const wid = options.attack?.weaponId || options.weaponId || (weapon ? weapon.id : 'other');
if (!this.currentWaveWeaponStats) this.currentWaveWeaponStats = {};

    this.currentWaveWeaponStats[wid] = { primaryDmg: 0, derivativeDmg: 0, dotDmg: 0, bossDmg: 0, hits: 0, crits: 0, totalDmg: 0 };
