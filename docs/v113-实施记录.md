# 1.13 武器成长、割草节奏与自动拾取

日期：2026-11-18；版本：1.13.0。本轮修改产品HTML、回归测试、图鉴生成器和说明，不改动历史分析数据或美术素材。

## 玩家可见变化

- 普通武器基础威力×1.25；突刺、挥扫、刃波和蓄力近战再×1.15，合计基础威力约+43.75%；专武整次基础预算×1.20。这是基础项增幅，不承诺最终DPS同比增长。
- 品质伤害倍率由`1/1.5/2.25/3.4`调整为`1/1.8/3.2/5.6`；属性成长由`1/1.35/1.8/2.4`调整为`1/1.6/2.5/4`。原生高阶武器仍除以最低品质倍率，避免重复放大。
- 普通武器按品质提供1～4羁绊点，每流派最多6点；专武计1点。低阶二合一保留羁绊，界面明确显示“点”。满槽从商店购入同阶直接升阶仍不减少现有槽数。
- 重锤主伤+45%、分流每弹70%、蓄压满蓄+55%；保留各自攻速/蓄力代价。回声每三次合格释放延迟复制60%，主伤代价降至5%。归航、轨道和疾行接入对应普通武器入口。
- 普通速射、普通暴击和持续跳伤不再触发全局停顿；重击/终结的短暂停顿有0.22秒共享触发冷却。保留局部形变、火花和音效。统计额外记录现实时间，避免停顿把显示DPS抬高。
- 第6波保留弓箭手教学，但刷怪批次数量增加延后一波。

## 回合结束自动拾取

成功结束回合时，先按同一拾取入口领取全部已生成掉落物，再结算收获、记录波次并清场：

1. 金币立即进入钱包，新发行部分给经验；旧储蓄返还不重复给经验。
2. 独立经验掉落正常升级，强化选择进入奖励队列。
3. 宝箱进入奖励队列，仍由玩家选择领取或回收。
4. 红心正常治疗，缝合针盒与溢流护盾效果生效。
5. 旧存档尚未返还的储蓄直接到账，不必再等下一波。

只领取真实掉落物，不自动击杀存活敌人或拆毁场景道具。失败不领奖；重复调用结算不增发。商店显示自动回收统计。第20波同样先领取掉落再进入胜利流程。

## 机制与稳定性修复

- 点射分三次释放并重新索敌；散射共享四弹预算；追踪齿轮转向寻敌；轨道共享每目标接触冷却；脉冲环扩散判定；封印刻针三击范围引爆；触发短杖冲刺后震波。
- 折返镰与双相飞轮分配去返段预算；分光轮盘回收触发折返点残光。归航修正去返伤害与回收冷却，牵引接头影响返程速度。
- 接入滑移轴、双充能电池、静息治疗、余热推开、拾取护盾、红心治疗修正、持续击杀护盾、条件增伤、构装加速、货币预算、刷新折扣、赊账、出售比例、首次刷新适配和侧弹预算等入口。
- 防滑鞋底改为接触减伤15%、移速-4%，替代原先没有玩家位移系统支持的描述；静默齿座不再通过全局属性误扣构装与持续伤害。
- 无尽生命倍率直接应用到实际生成敌人，与图鉴同源。
- 修正读档商店入口和角色/武器挂载顺序；保存锁定商品、刷新次数、专武改装次数、保险状态、Boss候选、奖励种子、债务和上一波结算。新局重置一次性保险。
- 伤害账本排除场景道具、区分真实DOT、跨波重置并保存波次快照；溢流治疗不再削减已有较高护盾。
- 清理死亡和清场实体，释放临时资源时保留工厂共享几何体和缓存材质。

## 验证与证据

- `node tests/run.cjs`：178项通过，包括新增真实入口验证；更新因本轮有意改变的旧数值快照，保留预算守恒、冷却、去重和奖励幂等验证。
- `node analysis/optimization-benchmark-v1.13.cjs`：当前结果写入同名JSON，附本轮和优化前源码指纹。六把I阶合成一次后的理论整套损失约2%～5%，此前约39%～42%；以实际输出文件为准。
- 固定构筑Boss对照仍使用相同装备数量、品质、属性和种子，包含品质羁绊变化的收益；不是单独基础增伤的因果估计。脚本走位未专门优化近战。
- 固定采购流程尝试20波；仍有种子提前失败。脚本放弃核心，满槽后不主动优化普通武器替换，结果不代表真人胜率或全流程难度通过。
- 真实Chrome验收覆盖进入战斗、混合新武器释放、远处掉落结算、升级/宝箱奖励、保存退出和读档继续。截图和结果在`artifacts/v113/`；软件WebGL环境不用于判断真实设备帧率。
- 两份自动图鉴按包版本输出为`weapon-catalogue-v1.13.json`和`content-catalogue-v1.13.json`，保留旧版文件。
