# 《余烬回路》游戏测试台

这是独立于正常游戏入口的本地测试工具。使用当前 `terrabrotato.html` 的真实脚本，不复制一套战斗实现，也不修改产品HTML。

## 启动

需要Node.js 18及以上；当前工作区使用Node.js 20。双击本目录中的 **启动测试工具.cmd**，终端启动服务后会自动打开浏览器。

也可以在项目目录执行：

```powershell
node tools/test-server.cjs
```

- 测试台：http://127.0.0.1:8765/test
- 普通游戏：http://127.0.0.1:8765/
- 关闭服务终端或按Ctrl+C停止；下次使用重新启动。
- 重复启动会复用本项目的已有测试台；若8765端口被其他程序占用，则自动尝试8766～8775，以终端显示的实际地址为准，不关闭其他进程。
- Windows启动脚本采用UTF-8与CRLF换行，并检测PATH、常见安装目录及当前机器已有的Node路径。可执行 `tools\启动测试工具.cmd --check` 仅检查启动器与Node版本。
- 自动打开浏览器受限时，服务仍可使用，直接访问终端显示的地址。
- 游戏仍需要网络加载Three.js与Tailwind CDN；工具本身没有新增第三方依赖。
- 仅监听本机回环地址。导入的配置在浏览器本地读取，导出文件由浏览器保存，没有上传报告的接口。

## 最快开始

1. 在右侧选择快捷配置，或填写职业、波次、晶币。
2. 点击“载入场景”。新场景默认冻结，可以先观察再开始。
3. 使用“运行／冻结”连续测试，或“推进0.1秒／1秒”检查精确时刻。
4. 点击左侧游戏画面后，使用WASD移动、空格冲刺。编辑面板输入框不会误触游戏快捷键。
5. 在“记录”页导出测试报告；需要复用构筑时导出场景配置。

快捷配置包括第5/10波守关者测试、第14波幸运235经济测试、六剑羁绊测试。选择快捷配置只填入草稿，需要点击载入才生效。旧截图压力配置属于手工构筑，不代表正常收益。

## 场景与战斗

- 目标波次支持1～200，职业、种子、波次和起始晶币通过载入场景生效；载入会重置本局、波次历史与测试随机序列。
- 仅Boss模式关闭自动刷怪与场景道具，并移除已有普通怪、预警、场景道具与敌方弹丸；手动生成怪物仍可使用。没有Boss的波次在此模式下会是空场。
- 无敌和速度可即时切换。无敌仅阻止玩家受伤，报告记录拦截次数；不会改变敌人伤害配置。
- 0.25～4倍速度只影响战斗时间。推进固定秒数不受速度倍率影响，会调用完整战斗更新，以不超过1/60秒的小步执行；发生结算或奖励选择时立即停止，不自动帮玩家领奖或跳下一波。
- 触发预警会冻结并重新锁定Boss技能；设为半血可用于3位原创Boss，不会缩短已经开始的预警。使用步进查看预警、技能执行与硬直。
- 传送采用场内X/Z坐标，拒绝越界值；位置修改会清空输入并冻结。
- 立即冲刺重置冲刺冷却并触发，随后冻结；使用步进观察其位移与无敌。
- 计时归零不绕过Boss击杀要求；强制击败Boss属于测试操作，之后步进才能执行实际结算。
- 打开测试商店、生成测试宝箱会清理当前战斗实体，跳过当前战斗，不发放波次奖励。测试宝箱不计自然掉箱数量。测试这些按钮后的记录不适合作为正常流程通关证据。

## 构筑与属性

- 构筑页配置1～6把武器，品质不能低于该武器的最低品质。
- 饰品数量默认执行产品持有上限；勾选“忽略持有上限”可进行压力测试，但普通商店和宝箱仍执行产品规则。
- 属性页填写相对所选职业初始属性的额外增减量。饰品与羁绊单独计算，右侧数字为游戏实际生效面板。
- 应用构筑／属性会冻结战斗、重建武器并清理旧的友方攻击效果，不重置Boss阶段或波次统计；多次应用同一配置不会重复叠加。
- 修改职业需要重新载入场景，避免旧模型与新属性混用。修改波次、种子、起始晶币也需要重新载入。
- “回满生命”直接改当前生命，不记录为自然吸血或再生。

## 1.8规则、核心与专武测试

当前版本为1.11。选择测试难度1～5、指定Boss或随机袋，再点击载入。测试台不写入正常游戏的难度解锁记录。

- 构筑页可直接选择6种核心或无核心，应用后冻结；手动修改属于测试，不代表自然获得。
- 场景页“打开测试核心选择”清理战场后直接打开三卡奖励，不发放自然波次奖励；已持有核心时拒绝再次选择。正常游戏通过击败Boss、处理宝箱和升级后获得。
- 手动生成怪物新增重甲守卫、治疗萨满。验证治疗时先生成守卫并造成伤害，再观察萨满绿色范围与0.8秒治疗预警；不会治疗Boss或自身。
- 难度1的第5/10/15/20波Boss生命为1500/6000/10500/15000，再乘所选难度倍率1/1.25/1.55/1.9/2.3；同一波不同Boss生命一致。
- 验证完整奖励：载入Boss波→击败Boss→计时归零→推进→处理升级与核心→保留/放弃专武→商店。强制击杀属于测试操作，不能用于证明正常通关。
- 专武保留后才进入强化池；满槽显示替换与返款。出售或强化满级后，对应强化资格撤销。每次刷新最多1张强化卡，刷新不推进新商店保底。
- 属性页显示16项有效属性；可测试全伤害50%、闪避60%、近战范围封顶与远程继续增长。装备“盈锋转换器”后，查看商店每把武器的实际暴击倍率；属性总面板不把各武器不同的转化量写回全局。
- 构筑页可配置新4款普通武器与3款专武。场景配置保存武器ID与品质，不保存专武等级和分支；报告快照记录实际实例、等级、分支、核心候选与待处理专武。需要复现强化时走奖励→商店流程。
- 新服务只复用相同源码与工具协议的已有实例；旧服务占用8765时自动换端口，使用终端显示地址。

## 1.7 前期经济测试

1.9新增验证：主菜单/战斗HUD可打开“武器图鉴”，打开后暂停，关闭恢复原状态；商店“攻击详情”读取当前构筑。记录页报告新增每把武器的详细数值与核心资格，并记录瞬时特效/持续攻击数量；顶部摘要显示友方特效数量及96个上限。可用6种机制同屏构筑检查锁线、冷雾、哨位和电弧，测试配置不代表正常获取。

1.10新增验证：在“构筑”页选择Boss专武后，可直接设置强化0～3级与聚砧/裂地、聚猎/播簇、聚束/折域路线，再选择核心并载入。专属品质固定，配置导入/导出保留等级和路线。普通武器不能设置专武改装，同款专武不允许重复。建议先用零级观察冲击/协同充能与棱核回收，再对比三级及共鸣；单次跳级测试不代表正常获取经济。

验证正常奖励流程时：载入第5波→计时归零→击败Boss→推进0.1秒，依次处理专武与核心，再进入商店。“专武改装”不占四格货架，购买一次后其他专武也禁用，刷新不恢复，进入下一次新商店才恢复次数。图鉴和奖励页显示的是当前代码规则；1.9固定砂蜂与随机强化卡的旧说明不适用于本版。

1.11新增验证：内容图鉴现有武器22、道具26、Boss3、小怪8，支持名称搜索和独立波次/难度预览；从主菜单、HUD、暂停或商店进入，关闭后回到原状态。预览不改变本局，图鉴期间附着和陷阱也停止计时。

在构筑页可选择蚀刻喷口＋熵蚀协议，或凝霜雾灯＋霜凝协议；伏雷匣适配滞爆。新六件机制配件可直接配置，配件效果不会伪装成16项基础属性。顶部摘要与报告新增附着条目数量，便于检查同源刷新、死亡/换装清理和120条全局上限。使用无敌场景只验证机制，不据此评判通关平衡。

- 新增“第5波：旧截图六武器压力测试”，未选择核心，手工设置213晶币并允许配置巨兽鲨，用于对照旧构筑；不是正常流程或新版经济收益证明。水矢品质按II阶近似。
- “记录”页展示晶币拾取、收获、储蓄分配与结转；报告快照额外保存当前待返还晶币。储蓄分配指已附加到掉落上的金额，尚未拾取也计入分配；结转指波末仍在地面的整枚晶币。
- 收获不再发经验，内部保留小数成长，发钱时取整。普通怪货币发行受到每波预算约束，手动生成更多怪物也不能无限刷钱；Boss奖励另算。
- 当前五波脚本：`node analysis/early-game-benchmark.cjs`；长流程：`node analysis/progression-benchmark.cjs`。均读取当前产品，历史报告仅作对照，不代表当前验收。

## 品质概率抽样

属性页填写抽样波次、幸运和样本数，点击执行。抽样使用真实产品品质函数，表格同时展示理论概率与实测比例。

- 波次按填写值计算，不自动加1。验证“第14波结束后的商店”时填写15。
- 固定种子可复现同一规则抽样。
- 抽样使用独立随机序列，执行后恢复战斗随机函数，不消耗战斗中的随机状态。
- 它测试品质函数，不模拟候选池回退、商店去重或完整对局胜率。

## 配置、日志与报告

- 导出场景配置：保存当前面板草稿，包括尚未应用的修改。
- 导入场景配置：先校验职业、属性、品质、数量与上限；仅填入面板，不重置当前游戏。点击载入后应用。
- 导出测试报告：包含产品版本与源码SHA-256、已应用配置、运行开关、实际装备和属性、Boss阶段、当前及已结算波次统计、随机状态、最近200条操作／错误日志和最近一次抽样结果。
- 商店购买、升级和其他局内变化以报告的 `snapshot` 为准；`appliedConfig` 是最后通过测试面板应用的构筑，不是当前存档。
- 固定种子不等于录像回放。输入时机、轨道动画、实际运行帧率与测试中途操作仍可能影响整局结果；配置也不支持恢复到战斗中间的某一帧。
- 不依赖本工具计算职业通关率；测试无敌、跳波、传送与强制击杀都可能污染自然对局结论。
